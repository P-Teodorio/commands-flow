# FLuxo

- Coloque o arquivo templates na pasta do projeto que vai usar
-  Use o prompt abaixo (Vai virar um comando tambem):
```
Usando os templates em @<path-templates> crie os arquivos INDEX.md, CONTEXT.md e DISCOVERY.md de forma semantica baseado no nosso plano acima e coloque dentro do obisidian no vault:

- <path-vault>

Cada task vai ser separada por pasta que vai ter a seguinte  nomeclatura:

- TASK-<numero incremental> 
```
- Use o comando Flow Specify
- Use o comando Flow Clarify
- Use o comando Flow Plan
- Use o comando Flow Tasks
- Use o comando Flow Analyze
- Use o comando Flow Implement
- Use o comando Flow Review
